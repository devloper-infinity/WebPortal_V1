# Software Request & Task Tracker

Run `DatabaseScripts/SoftwareRequests_001_FullModule.sql`, then `SoftwareRequests_002_TaskAllocationImport.sql`, and grant the existing ERP menu right for `SoftwareRequests/Dashboard.aspx`. Software users/developers come from active `EmployeeInfo` department 12 employees.

Workflow: `New → Under Review → Approved → Assigned → In Progress → On Hold → Testing → Completed` or `Rejected/Cancelled`.
